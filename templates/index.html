Bu API nima beradi?

Tezkor

15 daqiqalik cache, optimallashtirilgan so'rovlar va indekslangan bazani ta'minlaydi.

Ko'p tilli

Har bir oyat 4 tilda: arabcha asl matn, o'zbekcha, ruscha va inglizcha tarjimalar.

Filter & Qidiruv

Sura raqami, nozil bo'lgan joy, matn bo'yicha qidirish imkoniyatlari.

Audio

Arabcha qiroat audiolari va o'zbekcha ovozli tarjima fayllari.

PDF Kitoblar

Qur'on PDF kitoblari barcha tillarda yuklab olish uchun.

Limit yo'q

Rate limit yo'q. Har qanday loyihangizda erkin foydalaning.

🔍 Filter Parametrlari
Query parametrlari bilan ma'lumotlarni moslashtiring
Endpoint Parametr Turi Tavsif Misol
/api/v3/suras/ number integer Sura raqami bo'yicha ?number=1
/api/v3/suras/ revelation_place string Nozil bo'lgan joy (Makka/Madina) ?revelation_place=Makka
/api/v3/suras/ name string Sura nomi bo'yicha qidirish (barcha tillarda) ?name=fotiha
/api/v3/ayahs/ sura integer Sura ID bo'yicha filter ?sura=1
/api/v3/ayahs/ number integer Oyat raqami ?number=7
/api/v3/ayahs/ search string Matn bo'yicha qidirish (4 tilda) ?search=bismillah
/api/v3/authors/ language string Til bo'yicha: uz, ar, ru, en ?language=uz
/api/v3/books/ language string Til bo'yicha filter ?language=ar
Barcha listlar page integer Sahifa raqami (30 ta/sahifa) ?page=2
